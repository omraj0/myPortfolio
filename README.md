# Om Raj - Portfolio

Personal portfolio site with a terminal / developer theme.

**Live:** https://omraj0.github.io/myPortfolio/

## What is in it

- Hero with a typing terminal and rotating role line
- Impact numbers from my current role, animated on scroll
- Experience timeline, filterable skills grid and project cards
- Earlier projects (collapsed), contest ratings and education
- Light and dark themes, saved between visits
- Command palette: press `Ctrl K` (or `/`) to jump to any section, open the resume or copy my email
- Responsive from phones to wide desktops, keyboard accessible, respects reduced-motion settings

## Stack

Plain HTML, CSS and vanilla JavaScript. No framework and no build step, so it deploys straight to GitHub Pages.

```
index.html
assets/
  css/style.css
  js/main.js
  img/            photo, favicon, social preview image
  Om_Raj_Resume.pdf
```

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

GitHub Pages serves the `master` branch from the repository root. Push to `master` and the site updates.
